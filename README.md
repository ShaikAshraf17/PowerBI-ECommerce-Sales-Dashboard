# PowerBI E-Commerce Sales Dashboard

## Project Overview
Interactive Power BI dashboard built using the Sample Superstore dataset.

## KPIs
- Total Sales
- Total Profit
- Total Orders
- Profit Margin %

## Visualizations
- Sales Trend Analysis
- Sales by Category
- Profit by Region
- Category-wise Sales Distribution
- Interactive Slicers

## Tools Used
- Power BI Desktop
- DAX
- Data Visualization
